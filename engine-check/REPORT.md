## 검증 내용

1. **4개 엔진 교차 검증** — 1900-01-01 ~ 2050-12-31 매일 (55,152일), `crosscheck.mjs`
   - 일주: 4개 모두 일치 (불일치 0)
   - 연주·월주 (KST 정오 기준): manseryeok vs lunar-javascript 불일치 0
   - KASI 기반 음력 3종: 2050-02-21 ~ 03-22 (30일)만 manseryeok가 하루 어긋남. 천문 계산상 그달 합삭이 2050-02-22 00:02 KST (자정 2분 뒤)인 경계 사례
   - manseryeok 음력→양력 왕복 실패 0
2. **KASI 공식 서비스 대조** — 193일 표본 (무작위 140일 + 한·중 음력이 갈리는 날 + 윤달 + 문제 날짜), `kasi.mjs` → `kasi-result.json`
   - korean-lunar-calendar 음력: 193/193 일치
   - 일진(일주): 193/193 일치
   - manseryeok 음력: 2050년 3일만 불일치 (출생일에는 해당 없음)
3. **절기 시각** — 2024년 12절 manseryeok vs lunar-javascript 최대 1분 차이. 입춘 2024-02-04 17:27 KST (KASI 발표와 같음)
4. **윤달·잘못된 입력** (`edge.mjs`)

## 설계에 반영할 사항

- **출생 시간 없으면 절입일 출생자의 연·월주를 정할 수 없음.** 1940~2025년 중 3.3% (1,032일). 그날 00:00과 23:59 결과가 다르면 연·월주를 "확정 불가"로 두고 일주만 사용. 임의로 고르지 않음.
- 운세의 중심은 **일간(일주 천간) 오행 × 오늘 일진**으로 둠 → 출생 시간 없이도 모든 생일에서 검증된 값만 사용.
- 1954–61년(UTC+8:30)·서머타임 연도는 시각 기준이 30~60분 다름. 시간을 받지 않으므로 일주에는 영향 없고, 절입이 자정 ±1시간에 걸린 날만 위 "확정 불가" 판정을 보수적으로 넓혀 처리.
- 음력 입력은 1900~2050년만 받음 (korean-lunar-calendar 범위).
- 운세 문구 규칙(오행 상생·상극 → 운세)은 계산이 아니라 콘텐츠 규칙이므로 "재미용"으로 표시.
